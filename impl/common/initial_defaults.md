# Recommended Initial Defaults

## Co-op settings

| Setting | Default |
|---------|---------|
| Maximum initial milestone players | 2 |
| Production maximum | 8 players, 8 independent viewports |
| Room model | One shared loaded room |
| Transition authority | Player 0 |
| Human/wolf form | Independent per player |
| Wolf Midna rider | One per wolf Link |
| Epona | One owned horse per player |
| Friendly fire | Off |
| Self-bomb damage | On |
| Player-player body blocking | Off (soft separation) |
| Attention distribution | Light or Balanced |
| Downed state | Enabled |
| Revive | Hold A nearby |
| Free-for-all pickups | Enabled |

## Inventory

| Aspect | Rule |
|--------|------|
| Permanent items | Global |
| Item-button loadout | Per player |
| Ammo, bombs, oil | Per player |
| Rupees | Per player |
| Bottle slots | Global unlock |
| Bottle contents | Per player |
| Dungeon/quest progression | Global |

## Enemy scaling (ordinary enemies)

| Players | Count multiplier | Per-enemy HP cap |
|--------:|:----------------:|:----------------:|
| 2 | 1.5× | 1.35× |
| 3 | 2.0× | 1.35× |
| 4+ | 2.5× cap | 1.35× |

Party damage: 1.00×. Party stagger: +25% per additional player, cap 1.75×. Party cooldown: very small or zero when full count scaling achieved.
